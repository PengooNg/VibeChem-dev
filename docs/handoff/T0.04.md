## Plan

### Assumptions
1. "pnpm workspace in `app/`" = one pnpm package rooted at `app/` with its own `pnpm-workspace.yaml` (pnpm 10 reads `onlyBuiltDependencies` from it: electron, esbuild) and `app/pnpm-lock.yaml`. pnpm 10.34.9 pinned via `packageManager` (Corepack).
2. "App name translated in 3 languages" = the window shows the i18n keys `app.name` and `app.tagline`, rendered once per language (en, ja, vi) with `i18next.getFixedT`, so all three files are visible at once. The brand name is the same in all three; the tagline shows the translation.
3. Fonts are bundled through the `@fontsource-variable/{inter,jetbrains-mono,noto-sans-jp}` npm packages (OFL-1.1 fonts, MIT packaging); Vite copies the woff2 files into the build, so nothing loads from the web. This avoids committing ~10 MB of CJK font binaries. Recorded in TECH_STACK §1.5 and THIRD_PARTY.md.
4. No preload script yet (nothing to expose until T0.10/T0.11). The window already uses `contextIsolation: true`, `sandbox: true`, `nodeIntegration: false` and a CSP meta tag (TECH_STACK §10).
5. `check.py --only app` maps to the existing summary lines: format/lint = `pnpm lint` (ESLint + Prettier check), types = `pnpm typecheck` (tsc), tests = `pnpm test` (Vitest). In the full run the app results merge into the same lines as the Python results. Missing `pnpm` or `app/node_modules` -> FAIL with a hint. CI does not run check.py until T0.06, so CI is unaffected.
6. Versions: newest release in the TECH_STACK line that is at least two weeks old (before 2026-11-09). Electron 45.2.3, Vite 7.3.8, TypeScript 6.0.3, React 19.2.9, Tailwind 4.3.5, ESLint 9.39.5, typescript-eslint 8.72.1, Prettier 3.9.10, Vitest 4.1.12, i18next 26.7.2 + react-i18next 17.1.13 (the 27/18 majors are < 3 weeks old), @playwright/test 1.65.0, @playwright/cli 0.1.23, electron-vite 5.0.0, shadcn CLI 4.23.0.
7. Emil Kowalski skills vendored from `emilkowalski/skills` at commit `64eb3deb9a5fbfa041faf783e0bc3fd635872e9c` (MIT, checked via GitHub API).
