## Question for Quan
May `vibechem_core` import openpyxl (and, for T1.06, jcamp)?
Recommended answer: **yes** — amend the §3.1 core row to "…, file-format libraries listed in §1.2/§11
(openpyxl, jcamp), imported only inside `vibechem_core/io/` reader modules"; openpyxl becomes a
required runtime dependency of `vibechem-core` (MIT, pure Python, brings `et-xmlfile`), imported
lazily inside the Excel read function so `import vibechem_core` stays light. Read with
`load_workbook(read_only=True, data_only=True)` (cached cell values, no formulas evaluated).
Alternatives: (b) optional extra `vibechem-core[excel]` with a clear error when missing; (c) move the
Excel reader into `vibechem_engine` (splits readers across packages; not recommended).
Security note (🔒 step): openpyxl's docs recommend `defusedxml` against XML entity attacks. Python's
bundled expat (≥ 2.4) already limits entity expansion ("billion laughs"), so I propose no defusedxml,
plus a test that a malformed/oversized-entity xlsx raises our import error. Say if you want defusedxml.

Assumptions
- Readers return a plain result object (columns as name → NumPy array, plus suggested roles and
  warnings) shaped after DATA_MODEL §2.5 `suggested_roles` / `warnings`; building a `SpectralDataset`
  from committed roles is part of this step only as a helper if needed by tests (A2).
- Spectral columns = header cells that parse as finite numbers forming a monotonic run (≥ 2 columns);
  axis values = those numbers; unit guessed from range (nm vs cm-1) — METHODS/DATA_MODEL do not define
  the guess; I will mark it "suggested" only (user confirms at commit), no stop.
- Headerless two-column files (Bruker `.dpt`): one spectrum, first column = axis, second = intensity.
- Lines starting with `;` or `#` are comments (Quasar `AsciiColReader` behaviour, as tests).
- Delimiter: `,` for csv, tab for tsv, `auto` sniffs with `csv.Sniffer` over `, ; \t` and whitespace.
- Warning/error codes: only those in DATA_MODEL §7; new ones (e.g. non-numeric spectral cell) are
  proposed in DATA_MODEL §7 in this PR before use.
