## Plan
**Goal (Done when):** API tests pass; unauthorised request → 401.

**Assumptions**
1. Base URL prefix `/api/v1` (DATA_MODEL §1); all endpoints, `/health` included, need the token.
2. Production allowed origin is the placeholder `app://vibechem` (DATA_MODEL §1 "e.g."; fixed in T0.11). No Origin header is allowed. Dev mode (`VIBECHEM_DEV=1`) also allows any `http://localhost:<port>` (the Vite dev server port is not fixed). Everything else → 403 `ORIGIN_FORBIDDEN`.
3. CORS for the allowed origins only (no wildcard, ARCHITECTURE §3.7), exposing `X-VibeChem-Preview-Mode`, so T0.10's renderer can call the engine. Order: Origin check → CORS → token check.
4. 401/403 bodies are RFC 9457 problem details with codes `AUTH_TOKEN_INVALID` / `ORIGIN_FORBIDDEN` (§7), `message_key` `errors.api.auth_token_invalid` / `errors.api.origin_forbidden`; the EN/JA/VI strings are added when the UI shows engine errors (not in this step).
5. `/blocks` returns the static SNV entry of DATA_MODEL §2.3 (no block contract/registry yet — T1.x).
6. Skeleton SNV: per-row `(x - mean) / std` with `ddof=1` (Barnes 1989). Temporary; the real block (T1.07) follows METHODS.md.
7. `/skeleton/run` returns lines mode only (reference datasets have ≤ 120 spectra < `max_lines` 500): columns `x`, `y_0`…`y_{n-1}` (float32, 0-based row index), no colour column; header `X-VibeChem-Preview-Mode: lines`. Decimation when `n_points > width`: min/max per bucket (shape-preserving, shared `x`).
8. Request body validation errors use FastAPI's default 422 (no request-validation code in §7 yet — noted as open).
9. `testdata/` is not in the wheel: `python -m vibechem_engine.api --testdata-dir <path>`; default `find_testdata_dir()`.
10. Start-up handshake: one JSON line on stdout `{"event": "engine.listening", "port": <int>, "token": "<str>"}` after the socket is bound and listening; documented in DATA_MODEL §1.
