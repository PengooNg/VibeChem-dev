## Why stopped (DOC_CONFLICT)
METHODS.md N4 requires the block to emit warning `BLOCK_AXIS_NOT_UNIFORM` (params `max_deviation`) and to record "per point" as the derivative unit "in the output". Neither has a defined home:
1. **No block-warning channel.** `vibechem_core` has no way for a block to report a coded warning: `Block.apply` returns outputs only, errors.py defines only exceptions, no core module uses `warnings` or `logging`, and DATA_MODEL.md §3 `log` events carry `message` but no `code`/`params`. ARCHITECTURE.md has no ADR for it. Choosing one is a new pattern (CLAUDE.md §4 needs an ADR). T1.09 (N3) will need the same channel.
2. **No field for the derivative unit.** `SpectralDataset` has `signal_unit` (free text) and `history`; DATA_MODEL.md §4.2 says nothing about derivative units.
