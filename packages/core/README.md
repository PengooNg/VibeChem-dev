# vibechem-core (`vibechem_core`)

**Status:** Phase 1 in progress. Set up in T0.03; data model since T1.01; block contract and registry since T1.02a; state save/load and the scikit-learn wrapper since T1.02b; parameter schema export and value validation since T1.03; CSV/TSV and Excel reader since T1.05; JCAMP-DX and SPC readers and multi-file import since T1.06.

**Purpose:** the science library. It holds the spectral data model, file readers and writers, blocks (one file per block), the block registry, metrics and error codes. No pipeline execution, no API, no UI.

**Public API:** `vibechem_core.testing` (T0.07): test helpers shared by all packages — `assert_close`, `assert_reference`, `node_hash`, `check_golden`, `load_hypothesis_profile` (QA.md §3). `vibechem_core.reference_datasets` (T0.08): `load_reference_dataset(name)` returns a bundled reference dataset (`gasoline_nir`, `olive_oil_ftir`) as numpy arrays and `load_expected(name)` its published values; the files live in the repository's `testdata/`, not in the wheel (`testdata/datasets/PROVENANCE.md`). `vibechem_core.data` (T1.01): `SpectralDataset`, the immutable object behind the `Spectra` port type (fields as in DATA_MODEL.md §4.2), with `with_X()` and `subset()`; `Axis` (values + unit) and `Spatial` (pixel layout of unfolded image rows). Invalid inputs raise `ValueError`/`TypeError`. `vibechem_core.block` (T1.02a): the block contract — `Block` base class (metadata, `fit`/`apply` split), `Param`, `port()`, `State` (JSON values + named arrays), `save_state`/`load_state` (T1.02b: `state.json` + `arrays/<i>.npy`, never pickle, ADR-007), `BlockMeta` (`to_dict()` = `GET /blocks` entry, `to_detail_dict()` = `GET /blocks/{id}` with the parameter schema of DATA_MODEL.md §5, T1.03), `parse_params` (checks pipeline parameter values, raises `ParamError` with `BLOCK_PARAM_INVALID`), the `BLOCK_INPUT_*` and `BLOCK_PARAM_INVALID` error codes; `vibechem_core.registry.Registry` lists blocks by `block_id` in the `GET /blocks` shape; `vibechem_core.errors`: `VibeChemError`, `BlockError`, `BlockInputError`, `ParamError` (code, `message_key`, `params`), and `VibeChemWarning` since T1.08. `vibechem_core.wrap.TransformerBlock` (T1.02b): base class that turns a scikit-learn-style transformer (X only, same columns) into a fitted block; its state is the attributes `fit` added, stored as arrays and JSON values (the library itself is imported only in the block file). Dummy blocks `DummyOffset` (stateless), `DummyCenter` (fitted) and `DummySchema` (one parameter of every implemented schema type) live in `vibechem_core.testing`. `vibechem_core.io` (T1.05): `read_table(path, format_hint)` reads CSV/TSV (stdlib `csv`) and `.xlsx` (openpyxl, imported lazily) into a `TableImport` — `columns` (name → read-only 1-D NumPy array, the core form of the `Table` port type), `suggested_roles` and `warnings` as in DATA_MODEL.md §2.5; unreadable files raise `VibeChemError` with `IMPORT_FORMAT_UNKNOWN`/`IMPORT_FILE_INVALID`. T1.06: `read_jcamp(path)` (wraps `jcamp`, imported lazily) and `read_spc(path)` (Galactic SPC, ported from orange-spectroscopy's copy of Rohan Isaac's `spc`) return the same `TableImport`, one row per spectrum, built by `spectra_import`; `read_file(path, format_hint)` picks the reader by extension and `read_files(paths, format_hint)` concatenates several files (a `source_file` column, union axis, `IMPORT_AXIS_MISMATCH` + `needs_interpolation`). T1.06b: `read_spa` (Thermo OMNIC, ported from orange-spectroscopy), `read_perkinelmer` (`.sp`, ported from orange-spectroscopy's copy of Specio, BSD-3), `read_wdf` (Renishaw WiRE, ported from renishawWiRE, MIT) and `read_opus(path, block)` (Bruker OPUS, wraps `brukeropus`, imported lazily), all dispatched by `read_file`. T1.07: `Param` also declares `wavelength_ranges` parameters (a tuple of `(low, high)` pairs as default; `parse_params` sorts each pair); first blocks in `vibechem_core.blocks.preprocess`: `cut.Cut`, `snv.SNV`, `msc.MSC` (fitted; optional `reference` input), `detrend.Detrend`, with the error codes `BLOCK_CONSTANT_SPECTRA` and `BLOCK_MSC_SLOPE_INVALID` defined in the package `__init__`. T1.08: `savgol.SavitzkyGolay` (wraps `scipy.signal.savgol_filter`; derivatives per axis unit, per point with warning `BLOCK_AXIS_NOT_UNIFORM` on an uneven axis) and `vibechem_core.errors.VibeChemWarning`, the coded warning blocks raise with `warnings.warn` (ARCHITECTURE.md ADR-010). More blocks follow in T1.09 and later.

**Allowed dependencies** (TECH_STACK.md §3.1): numpy (runtime dependency since T0.07), scipy, scikit-learn (runtime dependency since T1.02b), approved chemometrics libraries from TECH_STACK.md §11 (imported only inside block files), file-format libraries from TECH_STACK.md §1.2/§11 (openpyxl since T1.05, jcamp since T1.06, brukeropus since T1.06b; imported only inside `vibechem_core/io/`), and `vibechem_native` (optional).
**Never imports:** `vibechem_engine`, fastapi, pyarrow, anything UI.

**Tests:** `packages/core/tests/`, which mirrors `src/vibechem_core/` exactly (`test_<module>.py`).
