# vibechem-core (`vibechem_core`)

**Status:** Phase 1 in progress. Set up in T0.03; data model since T1.01; block contract and registry since T1.02a; state save/load and the scikit-learn wrapper since T1.02b; parameter schema export and value validation since T1.03.

**Purpose:** the science library. It holds the spectral data model, file readers and writers, blocks (one file per block), the block registry, metrics and error codes. No pipeline execution, no API, no UI.

**Public API:** `vibechem_core.testing` (T0.07): test helpers shared by all packages — `assert_close`, `assert_reference`, `node_hash`, `check_golden`, `load_hypothesis_profile` (QA.md §3). `vibechem_core.reference_datasets` (T0.08): `load_reference_dataset(name)` returns a bundled reference dataset (`gasoline_nir`, `olive_oil_ftir`) as numpy arrays and `load_expected(name)` its published values; the files live in the repository's `testdata/`, not in the wheel (`testdata/datasets/PROVENANCE.md`). `vibechem_core.data` (T1.01): `SpectralDataset`, the immutable object behind the `Spectra` port type (fields as in DATA_MODEL.md §4.2), with `with_X()` and `subset()`; `Axis` (values + unit) and `Spatial` (pixel layout of unfolded image rows). Invalid inputs raise `ValueError`/`TypeError`. `vibechem_core.block` (T1.02a): the block contract — `Block` base class (metadata, `fit`/`apply` split), `Param`, `port()`, `State` (JSON values + named arrays), `save_state`/`load_state` (T1.02b: `state.json` + `arrays/<i>.npy`, never pickle, ADR-007), `BlockMeta` (`to_dict()` = `GET /blocks` entry, `to_detail_dict()` = `GET /blocks/{id}` with the parameter schema of DATA_MODEL.md §5, T1.03), `parse_params` (checks pipeline parameter values, raises `ParamError` with `BLOCK_PARAM_INVALID`), the `BLOCK_INPUT_*` and `BLOCK_PARAM_INVALID` error codes; `vibechem_core.registry.Registry` lists blocks by `block_id` in the `GET /blocks` shape; `vibechem_core.errors`: `VibeChemError`, `BlockError`, `BlockInputError`, `ParamError` (code, `message_key`, `params`). `vibechem_core.wrap.TransformerBlock` (T1.02b): base class that turns a scikit-learn-style transformer (X only, same columns) into a fitted block; its state is the attributes `fit` added, stored as arrays and JSON values (the library itself is imported only in the block file). Dummy blocks `DummyOffset` (stateless), `DummyCenter` (fitted) and `DummySchema` (one parameter of every implemented schema type) live in `vibechem_core.testing`. Blocks themselves follow in T1.07 and later.

**Allowed dependencies** (TECH_STACK.md §3.1): numpy (runtime dependency since T0.07), scipy, scikit-learn (runtime dependency since T1.02b), approved chemometrics libraries from TECH_STACK.md §11 (imported only inside block files), and `vibechem_native` (optional).
**Never imports:** `vibechem_engine`, fastapi, anything UI.

**Tests:** `packages/core/tests/`, which mirrors `src/vibechem_core/` exactly (`test_<module>.py`).
